# UltimateNotePad — Editor-only Fix v1.3

## 目的
- **左のメニュー・メモ一覧は変更しない**（幅、検索欄、メモカードの大きさ、余白、文字サイズも以前どおり）。
- スクロールバーが出ていた右側のメモ編集領域だけをコンパクトにする。
- 保存ボタンは常に見えるように維持する。
- メモ一覧は多数あるときだけスクロールする。

## 導入
1. ZIPの内容を `/workspaces/UltimateNotePad/` に配置してください。
2. 既存の `templates/index.html`, `static/css/animations.css`, `static/js/create-modal.js`, `static/js/date-jst.js` を上書きします。
3. **新規追加:** `static/css/editor-fit.css`
4. 既存の `static/css/style.css` と `static/js/autosave.js` は変更しません。
5. **v1.2の `layout-compact.css` はこのHTMLでは読み込みません**。ファイルが残っていても構いません。
6. ブラウザで Ctrl+Shift+R を押して更新してください。

## 変更点
- v1.1のサイドバーHTML・CSSをベースにしたため、v1.2で変わったメニューのスタイルは戻ります。
- `editor-fit.css` のみで高さ制御、本文入力欄の縮小、保存ボタンの配置調整を実施。
- アニメーション・モーダル・日本時間変換・自動保存は維持。

## 注意
長い本文を切り捨てないため、本文入力欄内部でのスクロール操作はできますが、**見えるスクロールバーはメモ一覧だけ**にしています。
ページ全体・編集パネルそのものはスクロールしません。
画面の高さが極端に低い場合やブラウザ拡大率が高い場合は、一部の表示領域が小さくなる可能性があります。
